## Sobre a aplicação

Aplicação web para registar problemas informáticos nas salas da escola e acompanhar o estado dos pedidos.

É possível registar um pedido com o nome do requerente, a sala, o equipamento e a descrição do problema. Também é possível atualizar o estado do pedido e escrever uma observação técnica.

## Como executar

É necessário ter Java e Maven instalados.

1. Abrir um terminal na pasta do projeto.
2. Executar:

   bash
   mvn jetty:run //permite abrir a página

   Abrir a aplicação no endereço:

http://localhost:8080/

Abrir pedidos : http://localhost:8080/pedidos
